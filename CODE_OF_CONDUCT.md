# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: treat people with respect. Harassment, personal attacks, and demeaning
or exclusionary behaviour are not acceptable, in issues, pull requests, commit
messages, or anywhere else this project happens.

Report a problem to <tony@git-pull.com>. Reports are handled privately, and the
maintainers will not retaliate against anyone who makes one in good faith.

The full text, including the enforcement guidelines the maintainers follow, is
at the link above.
